### OpenClaw Memory Architecture (from docs)

**Two default layers:**
1. `memory/YYYY-MM-DD.md` — daily log, read today + yesterday at session start
2. `MEMORY.md` — curated long-term, main session only

**Enhancements available:**
- Vector semantic search (need embedding API key: OpenAI, Gemini, Voyage, or Mistral)
- Hybrid search = BM25 keyword + vector semantic (best of both worlds)
- MMR re-ranking = prevents duplicate/redundant results
- Temporal decay = recent memories rank higher (30-day half-life recommended)
- Session memory indexing (experimental) = search past conversation transcripts
- QMD backend (experimental) = BM25 + vectors + reranking, fully local
