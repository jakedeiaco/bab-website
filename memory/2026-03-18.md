## BAB Scheduler Fixes

### Bugs Fixed
1. **Gold tier showing limit of 4** — `getClassLimitForTier` used `null ?? 4` which evaluates to `4` in JS (nullish coalescing treats null as missing). Fixed to use `hasOwnProperty` check instead.

2. **Railway crashes** — Async email functions (`sendConfirmationAsync` etc.) were called with `try/catch` which doesn't catch promise rejections. The fire-and-forget wrappers already had their own `.catch()` inside `sendAsync`. Added global `unhandledRejection` + `uncaughtException` handlers as safety net.

3. **Admin email not firing when member email fails** — All email functions sent member email first with `await`, then admin. If member send failed (Resend sandbox), function bailed before admin notification. Fixed by wrapping each send in independent try/catch blocks.

4. **Phone number missing from bookings** — Booking endpoint wasn't auto-populating phone from member profile. Fixed to pull phone from member token lookup when not supplied in request.

5. **Admin email plain text** — Upgraded admin notification to match member email format (styled HTML, Google Calendar link, member contact info).
