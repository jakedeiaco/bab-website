### Calendar Export Timezone Bug — Round 2 FIXED ✅
**Problem:** ICS exports had floating datetimes with no timezone → members' calendar apps interpreted times in device locale → wrong times or wrong days (reported by Roshaan for 4pm class)

**Root cause:** `gcFmt()` computed Pacific offset from `new Date()` (today) instead of the actual class date. For classes months away, this caused off-by-1-hour errors at DST boundaries.

**Fix deployed:**
1. `gcFmt()`: Offset now computed from actual class date, not current date
2. `buildIcsUrl()`: Switched from floating datetime to `DTSTART;TZID=America/Los_Angeles:YYYYMMDDTHHMMSS` format — calendar app now handles DST automatically

**Result:** Both Google Calendar + Apple/Outlook ICS now timezone-correct regardless of when class is booked vs. when it occurs ✅
